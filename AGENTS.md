# Project instructions

## Language

Use English for all project artifacts: source code, identifiers, comments,
documentation, skill instructions, user-facing plugin text, issues, pull requests,
commit messages, and branch names. Continue conversations in the user's preferred
language unless they ask otherwise.

## Workflow

Create an issue before starting a feature and work on a branch linked to that
issue. Keep main unchanged until the work is complete and validated.

Use official OpenAI documentation for plugin architecture and packaging. Consult
current library and CLI documentation through Context7 when applicable.

Keep the plugin minimal. Add components only when the current use case needs them.
Distinguish manifest validation and successful installation from behavioral tests
in a fresh Codex conversation. Do not report unperformed tests as passing.
